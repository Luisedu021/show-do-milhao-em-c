# Show do Milhão - C/C++ Trivia Game 💰🎤

Welcome to my **Show do Milhão** repository! This project is a terminal-based trivia game inspired by the classic Brazilian TV show "Who Wants to Be a Millionaire?". 

Developed as part of my Computer Science journey at UFMS, this project focuses on applying advanced C/C++ concepts, specifically managing data persistently and efficiently through memory manipulation.

## 🚀 Key Features

* **Question Randomizer**: A shuffling algorithm that ensures a unique set of questions for every game session.
* **Hint System**: Players can request hints during the game to help them choose the correct alternative.
* **Data Persistence**: All questions, alternatives, and correct answers are securely stored in and read from a **binary file**.

## 🧠 Technical Concepts Applied

To make this game work, I heavily utilized the following low-level programming concepts:

* **Binary File I/O**: Reading and manipulating `.bin` files to load the game's database dynamically.
* **Pointers & Memory Management**: Directly manipulating memory addresses to pass data efficiently between the game's systems.
* **Functions & Modularization**: Breaking down the game logic (menus, validation, scoring) into reusable and clean functions.
* **Structs**: Organizing complex data types to group a question, its hints, and its alternatives together.

## 🛠️ Technologies & Tools
* **Language**: C / C++
* **Core Concepts**: Pointers, Binary Files, Structs, Randomization algorithms
